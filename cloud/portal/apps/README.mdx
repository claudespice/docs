# Apps

**Apps** are self-contained instances of Spice OSS Runtime, running in Spice.ai Cloud Platform.

Each app has a unique API Key and owned by individual accounts or [**organizations**](/cloud/portal/organizations).

### Learn how to:

* [Transfer an app to another organization](/cloud/portal/apps/transfer)
* [Connect an app with your existing GitHub repository](/cloud/portal/apps/connect-github)
* [Create and toggle custom Dataset and Views](/cloud/portal/datasets-and-views)
