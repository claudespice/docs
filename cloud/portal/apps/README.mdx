# Apps

**Apps** are self-contained instances of Spice OSS Runtime, running in Spice.ai Cloud Platform.

Each app has a unique API Key and owned by individual accounts or [**organizations**](../organizations).

### Learn how to:

* [Transfer an app to another organization](transfer)
* [Connect an app with your existing GitHub repository](connect-github)
* [Create and toggle custom Dataset and Views](../datasets-and-views)
