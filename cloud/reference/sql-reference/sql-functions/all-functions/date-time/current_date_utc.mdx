---
description: Returns the current date of the system based on the UTC timezone.
---

# CURRENT\_DATE\_UTC

### Syntax

#### CURRENT\_DATE\_UTC() → date

**Examples**

```sql
SELECT CURRENT_DATE_UTC()
-- 2021-07-02
```
```sql
SELECT CURRENT_DATE_UTC
-- 2021-07-02
```
### Usage Notes

This function can be called without the parentheses.
