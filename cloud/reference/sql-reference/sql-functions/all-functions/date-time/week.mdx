# WEEK

### Syntax

#### EXTRACT(WEEK FROM _date\_timestamp\_expression_ string) → bigint

* date\_timestamp\_expression: A `DATE` or `TIMESTAMP` expression.

**Examples**

```sql
SELECT EXTRACT(WEEK FROM TIMESTAMP '2019-08-12 01:00:00.123456')
-- 33
```
```sql
SELECT EXTRACT(WEEK FROM DATE '2019-08-12')
-- 33.
```
```sql
SELECT EXTRACT(WEEK FROM CAST('2019-08-12 01:00:00' AS TIMESTAMP))
-- 33
```
### Usage Notes

This function uses the [`EXTRACT`](/cloud/reference/sql-reference/sql-functions/all-functions/date-time/extract) function. When using the [`CAST`](/cloud/reference/sql-reference/sql-functions/all-functions/conversion/cast) function, timestamps containing milliseconds are not allowed.
