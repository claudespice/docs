# HOUR

### Syntax

#### EXTRACT(HOUR FROM _date\_timestamp\_expression_ string) → bigint

* date\_timestamp\_expression: A `TIME`, `TIMESTAMP`, or `DATE` expression.

**Examples**

```sql
SELECT EXTRACT(HOUR FROM TIMESTAMP '2019-08-12 01:10:30.123456')
-- 1
```
```sql
SELECT EXTRACT(HOUR FROM TIME '01:10:30.123456')
-- 1
```
```sql
SELECT EXTRACT(HOUR FROM CAST('2019-08-12 01:10:30' AS TIMESTAMP))
-- 1
```
### Usage Notes

This function uses the [`EXTRACT`](/cloud/reference/sql-reference/sql-functions/all-functions/date-time/extract) function. When using the [`CAST`](/cloud/reference/sql-reference/sql-functions/all-functions/conversion/cast) function, timestamps containing milliseconds are not allowed.
