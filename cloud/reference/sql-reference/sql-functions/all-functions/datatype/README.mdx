# Datatype

| Function Name                 | Description                                                  |
| ----------------------------- | ------------------------------------------------------------ |
| [IS\_BIGINT](is\_bigint)   | Returns TRUE if the input expression is a big integer value. |
| [IS\_DATE](is\_date)       | Returns TRUE if the input expression can be cast to a date.  |
| [IS\_INT](is\_int)         | Returns TRUE if the input expression is an integer value.    |
| [IS\_VARCHAR](is\_varchar) | Returns TRUE if the input expression is a varchar value.     |
| [SIZE](/cloud/reference/sql-reference/sql-functions/all-functions/datatype/size)               | Returns the number of entries in a map expression.           |
| [TYPEOF](/cloud/reference/sql-reference/sql-functions/all-functions/datatype/typeof)           | Reports the type (in string format) of the input expression. |
