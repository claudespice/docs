# Cryptography

| Function Name                   | Description                                        |
| ------------------------------- | -------------------------------------------------- |
| [AES\_DECRYPT](aes\_decrypt) | Decrypts a string produced by AES encryption.      |
| [AES\_ENCRYPT](aes\_encrypt) | Encrypts a string using AES encryption.            |
| [MD5](/cloud/reference/sql-reference/sql-functions/all-functions/cryptography/md5)                   | Computes the MD5 hash value of a string.           |
| [SHA](/cloud/reference/sql-reference/sql-functions/all-functions/cryptography/sha)                   | Computes the SHA-1 hash value of a string.         |
| [SHA1](/cloud/reference/sql-reference/sql-functions/all-functions/cryptography/sha1)                 | Computes the SHA-1 hash value of a string.         |
| [SHA256](/cloud/reference/sql-reference/sql-functions/all-functions/cryptography/sha256)             | Computes the 256-bit SHA-2 hash value of a string. |
| [SHA512](/cloud/reference/sql-reference/sql-functions/all-functions/cryptography/sha512)             | Computes the 512-bit SHA-2 hash value of a string. |
