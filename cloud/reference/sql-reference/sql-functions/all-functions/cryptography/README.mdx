# Cryptography

| Function Name                   | Description                                        |
| ------------------------------- | -------------------------------------------------- |
| [AES\_DECRYPT](aes\_decrypt) | Decrypts a string produced by AES encryption.      |
| [AES\_ENCRYPT](aes\_encrypt) | Encrypts a string using AES encryption.            |
| [MD5](md5)                   | Computes the MD5 hash value of a string.           |
| [SHA](sha)                   | Computes the SHA-1 hash value of a string.         |
| [SHA1](sha1)                 | Computes the SHA-1 hash value of a string.         |
| [SHA256](sha256)             | Computes the 256-bit SHA-2 hash value of a string. |
| [SHA512](sha512)             | Computes the 512-bit SHA-2 hash value of a string. |
