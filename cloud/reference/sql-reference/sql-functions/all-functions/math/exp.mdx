# EXP

### Syntax

#### EXP(_numeric\_expression_ NUMERIC) → FLOAT

* numeric\_expression: The exponent value to raise e to. This must be `DOUBLE`, `INTEGER`, or `FLOAT`.

**Examples**

```sql
SELECT EXP(1)
-- 2.718281828459045
```
```sql
SELECT EXP(10.0)
-- 22026.465794806718
```
