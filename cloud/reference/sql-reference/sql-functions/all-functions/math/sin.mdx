# SIN

### Syntax

#### SIN(_numeric\_expression_ int32) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT SIN(360)
-- 0.9589157234143065
```
#### SIN(_numeric\_expression_ float) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT SIN(510.89)
-- 0.9282211721815067
```
#### SIN(_numeric\_expression_ int64) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT SIN(360)
-- 0.9589157234143065
```
#### SIN(_numeric\_expression_ double) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT SIN(510.89)
-- 0.9282211721815067
```
