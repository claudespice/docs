# ATAN

### Syntax

#### ATAN(_inputValue_ FLOAT) → FLOAT

* inputValue: Floating-point input value, in the range (negative-infinity:positive-infinity)

**Examples**

```sql
SELECT ATAN(0)
-- 0.0
```
```sql
SELECT ATAN(1)
-- 0.7853981633974483
```
```sql
SELECT ATAN(-1)
-- -0.7853981633974483
```
```sql
SELECT ATAN(19564.7)
-- 1.5707452143321894
```
