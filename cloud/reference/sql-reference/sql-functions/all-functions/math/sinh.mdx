description: Computes the hyperbolic sine of the input expression.
---

# SINH

### Syntax

#### SINH(_numeric\_expression_ int32) → double

* numeric\_expression: Input expression.

**Examples**

```sql
SELECT SINH(1)
-- 1.1752011936438014
```
#### SINH(_numeric\_expression_ float) → double

* numeric\_expression: Input expression.

**Examples**

```sql
SELECT SINH(1.5)
-- 2.1292794550948173
```
#### SINH(_numeric\_expression_ double) → double

* numeric\_expression: Input expression.

**Examples**

```sql
SELECT SINH(1.5)
-- 2.1292794550948173
```
#### SINH(_numeric\_expression_ int64) → double

* numeric\_expression: Input expression.

**Examples**

```sql
SELECT SINH(1)
-- 1.1752011936438014
```
