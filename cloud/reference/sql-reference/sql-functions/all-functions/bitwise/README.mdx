# Bitwise

| Function Name                        | Description                                            |
| ------------------------------------ | ------------------------------------------------------ |
| [BIT\_AND](../aggregate/bit\_and) | Returns the bitwise `AND` of non-NULL input values.    |
| [BIT\_OR](../aggregate/bit\_or)   | Returns the bitwise `OR` of non-NULL input values.     |
| [LSHIFT](lshift)                  | Shifts the bits of the numeric expression to the left. |
| [RSHIFT](rshift)                  | Shifts the bits of the numeric expression to he right. |
| [XOR](xor)                        | Returns the bitwise XOR of two integers.               |
