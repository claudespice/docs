# Bitwise

| Function Name                        | Description                                            |
| ------------------------------------ | ------------------------------------------------------ |
| [BIT\_AND](../aggregate/bit\_and) | Returns the bitwise `AND` of non-NULL input values.    |
| [BIT\_OR](../aggregate/bit\_or)   | Returns the bitwise `OR` of non-NULL input values.     |
| [LSHIFT](/cloud/reference/sql-reference/sql-functions/all-functions/bitwise/lshift)                  | Shifts the bits of the numeric expression to the left. |
| [RSHIFT](/cloud/reference/sql-reference/sql-functions/all-functions/bitwise/rshift)                  | Shifts the bits of the numeric expression to he right. |
| [XOR](/cloud/reference/sql-reference/sql-functions/all-functions/bitwise/xor)                        | Returns the bitwise XOR of two integers.               |
