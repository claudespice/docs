# Aggregate

| Function Name                                         | Description                                                                                                                                                                                                                                                               |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [APPROX\_COUNT\_DISTINCT](approx\_count\_distinct) | Returns the approximate number of unique, non-null values in a column.                                                                                                                                                                                                    |
| [AVG](/cloud/reference/sql-reference/sql-functions/all-functions/aggregate/avg)                                         | Computes the average of a set of values.                                                                                                                                                                                                                                  |
| [BIT\_AND](bit\_and)                               | Returns the bitwise `AND` of non-NULL input values.                                                                                                                                                                                                                       |
| [BIT\_OR](bit\_or)                                 | Returns the bitwise `OR` of non-NULL input values.                                                                                                                                                                                                                        |
| [CORR](/cloud/reference/sql-reference/sql-functions/all-functions/window/count)                            | Calculates the Pearson correlation coefficient of the values expression1 and expression2. The function name must be enclosed in double quotes (“CORR”).                                                                                                                   |
| [COUNT](/cloud/reference/sql-reference/sql-functions/all-functions/window/count)                           | Returns the total number of records for the specified expression.                                                                                                                                                                                                         |
| [COVAR\_POP](../window/covar\_pop)                 | Returns the population covariance for non-NULL pairs across all input values.                                                                                                                                                                                             |
| [COVAR\_SAMP](../window/covar\_samp)               | Returns the sample covariance for non-NULL pairs across all input values.                                                                                                                                                                                                 |
| [HLL](/cloud/reference/sql-reference/sql-functions/all-functions/window/hll)                               | Uses HyperLogLog to return an approximation of the distinct cardinality of the input.                                                                                                                                                                                     |
| [LISTAGG](/cloud/reference/sql-reference/sql-functions/all-functions/aggregate/listagg)                                 | Concatenates a group of rows into a list of strings and places a separator between them.                                                                                                                                                                                  |
| [MAX](/cloud/reference/sql-reference/sql-functions/all-functions/aggregate/max)                                         | Returns the maximum value among the non-NULL input expressions.                                                                                                                                                                                                           |
| [MIN](/cloud/reference/sql-reference/sql-functions/all-functions/aggregate/min)                                         | Returns the minimum value among the non-NULL input expressions.                                                                                                                                                                                                           |
| [NDV](/cloud/reference/sql-reference/sql-functions/all-functions/window/ndv)                               | Returns an approximate distinct value number, similar to `COUNT(DISTINCT col)`. NDV can return results faster than using the combination of COUNT and DISTINCT while using a constant amount of memory, resulting in less memory usage for columns with high cardinality. |
| [STDDEV](/cloud/reference/sql-reference/sql-functions/all-functions/math/stddev)                           | Returns the standard deviation of non-NULL values in a column with a numeric data type. If all records inside a group are NULL, returns NULL.                                                                                                                             |
| [STDDEV\_POP](../math/stddev\_pop)                 | Returns the population standard deviation (square root of variance) of non-NULL values in a column with a numeric data type. If all records inside a group are NULL, returns NULL.                                                                                        |
| [STDDEV\_SAMP](../math/stddev\_samp)               | Returns the sample standard deviation (square root of sample variance) of non-NULL values in a column with a numeric data type. If all records inside a group are NULL, returns NULL.                                                                                     |
| [SUM](/cloud/reference/sql-reference/sql-functions/all-functions/aggregate/sum)                                         | Returns the sum of non-NULL input expressions.                                                                                                                                                                                                                            |
| [VAR\_POP](../window/var\_pop)                     | Returns the population variance of non-NULL records.                                                                                                                                                                                                                      |
| [VAR\_SAMP](../window/var\_samp)                   | Returns the sample variance of non-NULL records.                                                                                                                                                                                                                          |
