# Apps API

Apps are the primary resource in Spice.ai Cloud. Each app represents a deployed Spice runtime with its own configuration, datasets, models, and endpoints.

## List Apps

`GET` `https://api.spice.ai/v1/apps`

Returns a list of apps for the authenticated organization.

**Required scope:** `apps:read`

### Response

<Tabs>
<Tab title="200: OK">
```json
{
  "apps": [
    {
      "id": 123,
      "name": "my-app",
      "description": "My Spice app",
      "visibility": "private",
      "created_at": "2024-01-15T10:00:00.000Z",
      "cname": "us-west-2-prod-aws-data",
      "api_key": "abc123...",
      "tags": {
        "environment": "production",
        "team": "data"
      }
    }
  ]
}
```

**Response Fields:**

| Field         | Type           | Description                                  |
| ------------- | -------------- | -------------------------------------------- |
| `id`          | integer        | Unique app identifier                        |
| `name`        | string         | App name                                     |
| `description` | string \| null | App description                              |
| `visibility`  | string         | `public` or `private`                        |
| `created_at`  | string         | ISO 8601 timestamp                           |
| `cname`       | string         | Region identifier                            |
| `api_key`     | string \| null | Primary API key (for runtime authentication) |
| `tags`        | object \| null | Key-value tags                               |
</Tab>

<Tab title="401: Unauthorized">
```json
{
  "error": "Missing Authorization header"
}
```
</Tab>

<Tab title="403: Forbidden">
```json
{
  "error": "Insufficient scope. Required: apps:read"
}
```
</Tab>
</Tabs>

### Example

```bash
curl -H "Authorization: Bearer <token>" 
  https://api.spice.ai/v1/apps
```

## Create App

`POST` `https://api.spice.ai/v1/apps`

Creates a new app in the authenticated organization.

**Required scope:** `apps:write`

### Request Body

```json
{
  "name": "my-app",
  "cname": "us-west-2-prod-aws-data",
  "description": "My Spice app",
  "visibility": "private",
  "tags": {
    "environment": "production"
  }
}
```

**Request Fields:**

| Field         | Type   | Required | Description                                           |
| ------------- | ------ | -------- | ----------------------------------------------------- |
| `name`        | string | **Yes**  | App name (min 4 chars, alphanumeric and hyphens only) |
| `cname`       | string | **Yes**  | Region identifier (get from `/v1/regions`)            |
| `description` | string | No       | App description                                       |
| `visibility`  | string | No       | `public` or `private` (default: `private`)            |
| `tags`        | object | No       | Key-value tags for organization                       |

### Response

<Tabs>
<Tab title="201: Created">
```json
{
  "id": 123,
  "name": "my-app",
  "description": "My Spice app",
  "visibility": "private",
  "created_at": "2024-01-15T10:00:00.000Z",
  "production_branch": null,
  "api_key": "abc123...",
  "tags": {
    "environment": "production"
  },
  "config": {
    "spicepod": null,
    "registry": "ghcr.io",
    "image": null,
    "image_tag": null,
    "update_channel": "stable",
    "replicas": 1,
    "region": null,
    "node_group": null,
    "storage_claim_size_gb": null
  }
}
```

**Response Fields:**

| Field               | Type           | Description                                 |
| ------------------- | -------------- | ------------------------------------------- |
| `id`                | integer        | Unique app identifier                       |
| `name`              | string         | App name                                    |
| `description`       | string \| null | App description                             |
| `visibility`        | string         | `public` or `private`                       |
| `created_at`        | string         | ISO 8601 timestamp                          |
| `production_branch` | string \| null | Git branch for production deployments       |
| `api_key`           | string         | Primary API key                             |
| `tags`              | object \| null | Key-value tags                              |
| `config`            | object         | App configuration (see Config Object below) |

**Config Object:**

| Field                   | Type           | Description                                            |
| ----------------------- | -------------- | ------------------------------------------------------ |
| `spicepod`              | object \| null | Spicepod YAML configuration                            |
| `registry`              | string         | Container registry (e.g., `ghcr.io`)                   |
| `image`                 | string \| null | Container image name                                   |
| `image_tag`             | string \| null | Spice runtime version tag                              |
| `update_channel`        | string         | `stable`, `nightly`, `internal`, or `internal-sandbox` |
| `replicas`              | integer        | Number of replicas (1-10)                              |
| `region`                | string \| null | AWS region code                                        |
| `node_group`            | string \| null | Kubernetes node group                                  |
| `storage_claim_size_gb` | number \| null | Persistent volume size                                 |
</Tab>

<Tab title="400: Bad Request">
```json
{
  "error": "Validation error",
  "details": {
    "fieldErrors": {
      "name": ["App name must be at least 4 characters"]
    }
  }
}
```
</Tab>

<Tab title="403: Forbidden">
```json
{
  "error": "Organization has reached the maximum app limit"
}
```
</Tab>

<Tab title="409: Conflict">
```json
{
  "error": "App \"my-app\" already exists in this organization"
}
```
</Tab>
</Tabs>

### Examples

**cURL:**

```bash
curl -X POST https://api.spice.ai/v1/apps 
  -H "Authorization: Bearer <token>" 
  -H "Content-Type: application/json" 
  -d '{
    "name": "my-app",
    "cname": "us-west-2-prod-aws-data",
    "description": "My production app",
    "visibility": "private",
    "tags": {
      "environment": "production",
      "team": "data"
    }
  }'
```

**Python:**

```python
import requests

response = requests.post(
    "https://api.spice.ai/v1/apps",
    headers={
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json"
    },
    json={
        "name": "my-app",
        "cname": "us-west-2-prod-aws-data",
        "description": "My production app"
    }
)

app = response.json()
print(f"Created app {app['name']} with ID {app['id']}")
```

**Node.js:**

```javascript
const response = await fetch('https://api.spice.ai/v1/apps', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    name: 'my-app',
    cname: 'us-west-2-prod-aws-data',
    description: 'My production app'
  })
});

const app = await response.json();
console.log(`Created app ${app.name} with ID ${app.id}`);
```

## Delete App

`DELETE` `https://api.spice.ai/v1/apps/{appId}`

Soft deletes an app (sets `deleted_at` timestamp). The app will be stopped and its resources released.

**Required scope:** `apps:delete`

### Path Parameters

| Parameter | Type    | Description |
| --------- | ------- | ----------- |
| `appId`   | integer | The app ID  |

### Response

<Tabs>
<Tab title="204: No Content">
App deleted successfully. No response body.
</Tab>

<Tab title="404: Not Found">
```json
{
  "error": "App with ID 123 not found"
}
```
</Tab>
</Tabs>

### Example

```bash
curl -X DELETE https://api.spice.ai/v1/apps/123 
  -H "Authorization: Bearer <token>"
```

<Warning>
Deleting an app will stop all running deployments and delete associated resources. This action cannot be undone.
</Warning>

## App Lifecycle

1. **Create** - Create an app with basic metadata
2. **Configure** - Update the spicepod configuration
3. **Deploy** - Create a deployment (see [Deployments API](/cloud/api/management/deployments))
4. **Monitor** - Check deployment status and logs
5. **Update** - Modify configuration and redeploy
6. **Delete** - Remove the app when no longer needed

## Best Practices

### Naming Conventions

- Use descriptive, lowercase names with hyphens
- Include environment in name or tags: `my-app-prod`, `my-app-staging`
- Keep names under 32 characters

### Configuration Management

- Store spicepod configurations in version control
- Use tags to track versions and metadata
- Test configuration changes in a staging app first

### Scaling

- Start with 1 replica and scale based on load
- Monitor resource usage before increasing replicas
- Use appropriate replica counts for your plan tier

## Terraform

Use the `spiceai_app` resource to manage apps. See [Terraform Provider](/cloud/api/management/terraform#spiceai_app) for full documentation.

```hcl
resource "spiceai_app" "example" {
  name       = "my-app"
  cname      = "us-west-2-prod-aws-data"
  visibility = "private"

  spicepod = <<-YAML
    version: v1beta1
    kind: Spicepod
    name: my-app
    datasets:
      - name: taxi_trips
        from: s3://spiceai-demo-datasets/taxi_trips/2024/
        params:
          file_format: parquet
  YAML

  image_tag = "latest"
  replicas  = 2
}
```
