# Getting Started

Get up and running with Spice.ai Cloud Platform in just a few steps.

<Steps>
  <Step title="Sign in to the Portal with GitHub">
    Create your account by signing in with GitHub.

    [Sign in with GitHub](/cloud/getting-started/get-started/portal-login)
  </Step>
  <Step title="Create a Spice app">
    Set up your first Spice application in the portal.

    [Create a Spice app](/cloud/getting-started/getting-started/portal-login-1)
  </Step>
  <Step title="Add a dataset and query it">
    Connect a data source and run your first SQL query.

    [Add a Dataset and query data](/cloud/getting-started/get-started/step-2-add-dataset-and-query-data)
  </Step>
  <Step title="Add an AI Model and chat with it">
    Configure an LLM and interact with your data using natural language.

    [Add AI Model and chat with your data](/cloud/getting-started/get-started/step-3-add-ai-model-and-chat-with-your-app)
  </Step>
</Steps>
