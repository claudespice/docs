# Add a Dataset and query data

To add a dataset to the Spice app, navigate to the [**Code**](/cloud/portal/app-spicepod) tab.

Use the **Components sidebar** on the right to select from available **Data Connectors**, **Model Providers**, and ready-to-use **Datasets**.

### Adding a ready-to-use Dataset

1. Navigate to **Code** tab.
2. In **Components** sidebar, click the **Datasets** tab.

<Frame caption="Spice.ai app Code configuration">
  <img src="/images/CleanShot 2024-12-19 at 11.00.59@2x.png" alt="" />
</Frame>

3. Select and add the **NYC Taxi Trips** dataset
   1. Note the configuration has been added to the editor

<Frame caption="Add the NYC Taxi Trips dataset">
  <img src="/images/CleanShot 2024-12-19 at 11.00.38@2x.png" alt="" />
</Frame>

4. Click **Save** in the code toolbar and then **Deploy** on popup card that appears in the bottom right.

![](/images/CleanShot 2024-12-19 at 11.04.22.gif)

5. Navigate to the [**Playground**](/cloud/portal/playground) tab, open the dataset reference, and click on the `spice.samples.taxi_trips` dataset to insert a sample query into the SQL editor. Then, click **Run Selection**.

<Frame caption="Exexuting the sample query for the NYC Taxi Trips dataset.">
  <img src="/images/CleanShot 2024-12-19 at 11.09.40.gif" alt="" />
</Frame>

### \[Optional] Execute a SQL query using cURL

6. Go app **Settings** and copy one of the app API Keys.

<Frame caption="Getting an API Key from the app Settings.">
  <img src="/images/CleanShot 2024-12-19 at 12.25.51@2x.png" alt="" />
</Frame>

7. Replace `[API-KEY]` in the sample below with your API Key and execute from a terminal.

<Tabs>
<Tab title="cURL">

```sh
curl --request POST 
  --url 'https://data.spiceai.io/v1/sql' 
  --header 'Content-Type: text/plain' 
  --header 'X-API-KEY: [API-KEY]' 
  --data 'select * from spice.samples.taxi_trips limit 3'
```

</Tab>
</Tabs>

<Frame caption="Showing results from executing a sample NYC Taxi Trips dataaset query using cURL.">
  <img src="/images/CleanShot 2024-12-19 at 12.34.32@2x.png" alt="" />
</Frame>

🎉 Congratulations, you've now added a dataset and queried it.
