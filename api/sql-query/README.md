# SQL Query API

With Spice SQL Query, data backed by the Spice.ai Cloud Data Warehouse and connected [External Datasources](../../portal/external-data-sources.md) can be queried using SQL and results fetched over [HTTP](http-api.md) or [Apache Arrow Flight](apache-arrow-flight-api.md).

See [SQL Query Tables](broken-reference) for [community data](broken-reference) table definitions and the [SQL Reference](../../reference/sql-reference/) for documentation on supported SQL commands (ANSI-SQL).
