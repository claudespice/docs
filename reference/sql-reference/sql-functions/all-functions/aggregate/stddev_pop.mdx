---
description: >-
  Returns the population standard deviation (square root of variance) of
  non-NULL values in a column with a numeric data type. If all records inside a
  group are NULL, returns NULL.
---

# STDDEV\_POP

### Syntax

#### STDDEV\_POP(_numeric\_expression_ double) → double

* numeric\_expression: The set of records to calculate the population standard deviation for.

**Examples**

```sql
SELECT STDDEV_POP(gas_used) 
FROM eth.recent_blocks
-- 2.259665030506379
```
#### STDDEV\_POP(_numeric\_expression_ float) → double

* numeric\_expression: The set of records to calculate the population standard deviation for.

**Examples**

```sql
SELECT STDDEV_POP(gas_used) 
FROM eth.recent_blocks
-- 2.259665030506379
```
#### STDDEV\_POP(_numeric\_expression_ int32) → double

* numeric\_expression: The set of records to calculate the population standard deviation for.

**Examples**

```sql
SELECT STDDEV_POP(transaction_count) 
FROM eth.recent_blocks
-- 1.367021462155777
```
#### STDDEV\_POP(_numeric\_expression_ int64) → double

* numeric\_expression: The set of records to calculate the population standard deviation for.

**Examples**

```sql
SELECT STDDEV_POP(transaction_count) 
FROM eth.recent_blocks
-- 1.367021462155777
```
