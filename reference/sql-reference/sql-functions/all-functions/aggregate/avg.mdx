# AVG

### Syntax

#### AVG(_numeric\_expression_ NUMERIC) → FLOAT

* numeric\_expression: `DOUBLE`, `FLOAT`, `INTEGER`, `INTERVAL_DATE`, `INTERVAL_YEAR`

**Examples**

```sql
SELECT AVG(3)
-- 3.0
```
```sql
SELECT AVG("val")
-- -0.333333
```
