---
description: >-
  Returns the standard deviation of non-NULL values in a column with a numeric
  data type. If all records inside a group are NULL, returns NULL.
---

# STDDEV

### Syntax

#### STDDEV(_numeric\_expression_ double) → double

* numeric\_expression: The set of records to calculate the standard deviation for.

**Examples**

```sql
SELECT STDDEV(gas_used) 
FROM eth.recent_blocks
-- 2.2596650338461766
```
#### STDDEV(_numeric\_expression_ float) → double

* numeric\_expression: The set of records to calculate the standard deviation for.

**Examples**

```sql
SELECT STDDEV(gas_used) 
FROM eth.recent_blocks
-- 2.2596650338461766
```
#### STDDEV(_numeric\_expression_ int32) → double

* numeric\_expression: The set of records to calculate the standard deviation for.

**Examples**

```sql
SELECT STDDEV(transaction_count) 
FROM eth.recent_blocks
-- 1.3670214641762426
```
#### STDDEV(_numeric\_expression_ int64) → double

* numeric\_expression: The set of records to calculate the standard deviation for.

**Examples**

```sql
SELECT STDDEV(transaction_count) 
FROM eth.recent_blocks
-- 1.3670214641762426
```
