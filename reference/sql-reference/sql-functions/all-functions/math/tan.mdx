# TAN

### Syntax

#### TAN(_numeric\_expression_ double) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT TAN(180.8)
-- -6.259341891872157
```
#### TAN(_numeric\_expression_ int64) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT TAN(1200)
-- -0.08862461268886584
```
#### TAN(_numeric\_expression_ int32) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT TAN(1200)
-- -0.08862461268886584
```
#### TAN(_numeric\_expression_ float) → double

* numeric\_expression: The number in radians.

**Examples**

```sql
SELECT TAN(180.8)
-- -6.259341891872157
```
