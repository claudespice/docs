# ACOS

### Syntax

#### ACOS(_numeric\_expression_ NUMERIC) → FLOAT

* numeric\_expression: The number in radians. This must be `DOUBLE`, `INTEGER`, or `FLOAT`.

**Examples**

```sql
SELECT ACOS(0)
-- 1.5707963267948966
```
```sql
SELECT ACOS(1.0)
-- 0.0
```
```sql
SELECT ACOS(-1)
-- 3.141592653589793
```
