# TANH

### Syntax

#### TANH(_numeric\_expression_ double) → double

* numeric\_expression: Input expression to calculate tanh for.

**Examples**

```sql
SELECT TANH(1.5);
-- 0.9051482536448664
```
#### TANH(_numeric\_expression_ int64) → double

* numeric\_expression: Input expression to calculate tanh for.

**Examples**

```sql
SELECT TANH(1);
-- 0.7615941559557649
```
#### TANH(_numeric\_expression_ float) → double

* numeric\_expression: Input expression to calculate tanh for.

**Examples**

```sql
SELECT TANH(1.5);
-- 0.9051482536448664
```
#### TANH(_numeric\_expression_ int32) → double

* numeric\_expression: Input expression to calculate tanh for.

**Examples**

```sql
SELECT TANH(1);
-- 0.7615941559557649
```
