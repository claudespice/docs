---
description: Returns TRUE if the input expression evaluates to TRUE.
---

# ISTRUE

### Syntax

#### ISTRUE(_expression_ int64) → boolean

* expression: Input expression.

**Examples**

```sql
SELECT ISTRUE(1)
-- True
```
#### ISTRUE(_expression_ boolean) → boolean

* expression: Input expression.

**Examples**

```sql
SELECT ISTRUE(FALSE)
-- False
```
#### ISTRUE(_expression_ int32) → boolean

* expression: Input expression.

**Examples**

```sql
SELECT ISTRUE(0)
-- False
```
