# RIGHT

### Syntax

#### RIGHT(_string_ varchar, _length_ int64) → varchar

* string: String input parameter.
* length: Number of characters on the right to return.

**Examples**

```sql
SELECT "RIGHT"('Spice - SQL Engine', 6)
-- Engine
```
