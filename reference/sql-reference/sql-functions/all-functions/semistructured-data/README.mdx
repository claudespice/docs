# Semistructured Data

| Function Name                         | Description                                    |
| ------------------------------------- | ---------------------------------------------- |
| [ARRAY\_CONTAINS](array\_contains) | Returns whether a list contains a given value. |
| [MAP\_KEYS](map\_keys)             | Returns all keys from a map expression.        |
| [MAP\_VALUES](map\_values)         | Returns all values from a map expression.      |
