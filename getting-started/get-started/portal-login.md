# Step 1 - Portal Login

### Prerequisites

A GitHub account is required to access the Spice.ai platform. If you don't have one, you can [sign up here](https://github.com/signup).

### From the Spice.ai website

1. Go to [spice.ai](https://spice.ai) and click on **Login** or **Try for Free** in the top right corner.
2. You can also navigate directly by URL to [spice.ai/login](https://spice.xyz/login)

<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 09.37.44@2x.png" alt=""><figcaption><p>The Spice.ai website</p></figcaption></figure>

3. Click **Continue with GitHub** to grant authorization to login with your GitHub account.

<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 09.44.57@2x.png" alt=""><figcaption><p>Login with GitHub</p></figcaption></figure>

4. &#x20;Click **Authorize Spice AI Cloud Platform** to grant Spice AI read-only access to your **GitHub account** data.

<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 09.46.12@2x.png" alt=""><figcaption><p>Authorize Spice.ai Cloud Platform with GitHub</p></figcaption></figure>

5. You will be redirected to the new app setup page, to set a name and optionally add a model provider and select one of ready to use datasets.
   1. Enter a name for your application.
   2. Choose a model provider and enter the required API key. The app name must be a combination of lowercase and uppercase letters, numbers, or dashes, and should be longer than 3 characters.
   3. Optionally, select one or more of the available datasets to get started quickly.
   4. Click **Create application**.

{% hint style="info" %}
You can configure model providers and datasets later as needed.
{% endhint %}



<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 09.52.03@2x.png" alt=""><figcaption><p>Create first Spice.ai App</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 10.04.29@2x.png" alt=""><figcaption><p>Set name, select model and dataset</p></figcaption></figure>

<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 10.06.30@2x.png" alt=""><figcaption></figcaption></figure>

6. Once the app instance is loaded, you will be redirected to the app playground.

<figure><img src="../../.gitbook/assets/CleanShot 2024-12-19 at 10.15.09@2x.png" alt=""><figcaption><p>SQL Playground</p></figcaption></figure>

**Congrats, you've created your first** [**Spice app**](../../portal/apps/)**!**
